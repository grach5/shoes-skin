# Shoes&Skin — заметки по сборке сайта

Стек: чистый HTML5 + CSS3 (custom properties как дизайн-токены в `:root`) + vanilla JS, без сборки, без npm/Node. Шрифты — Google Fonts (`Fraunces` для заголовков, `Manrope` для текста). Иконки — инлайн SVG. Файлы: `index.html`, `styles.css`, `script.js`.

## Сделано

- Полная одностраничная структура: Hero → О нас → Услуги и цены → Галерея → Отзывы/доверие → Запись → Оплата → Контакты → Footer, плюс sticky-шапка с мобильным меню.
- Собственная палитра: тёплый графит (`#171512`/`#24211c`) + тёплый нейтральный бон (`#f4efe4`) + один акцент — состаренная латунь (`#b6905a` и производные). Сознательно не использованы дефолтные для «luxury minimal» комбинации (кремовый+терракота+сериф, почти чёрный+кислотный, газетная вёрстка, 01/02/03, градиентный текст, glassmorphism, эмодзи).
- Сигнатурный визуальный приём — мотив шва обуви (Blake stitch): пунктирная «строчка» как разделитель (используется в шапке под логотипом, в hero, в блоке записи) + анимация «блик лакированной кожи», проходящий по карточкам услуг при наведении (`.service-shine`) и по плитке «Лакированная кожа» в галерее.
- Услуги и цены — использованы ТОЧНО заданные позиции и суммы: Химчистка обуви — от 15 500 ₽; Реставрация обуви — от 15 900 ₽; Реставрация лаковой обуви — от 25 900 ₽.
- Галерея — 6 плиток, все на чистом CSS (градиенты/паттерны имитируют гладкую кожу, замшу, лак, экзотическую кожу, фурнитуру, дерево колодки), никаких стоковых фото.
- Отзывы/доверие — показаны только факты (рейтинг 5.0, 8 отзывов на 2ГИС), тексты отзывов НЕ придуманы и не выведены на сайт — только ссылка «Смотреть отзывы на 2ГИС».
- Форма записи → JS собирает сообщение и открывает `https://wa.me/79037995036?text=...` в новой вкладке (`script.js`, обработчик `submit` на `#bookingForm`). Подпись «Заявка откроется в WhatsApp» присутствует под кнопкой.
- Раздел «Оплата» — только информационный текст (карта на месте, наличные, СБП по QR), никаких полей для номера карты.
- Контакты — адрес основного филиала, `tel:+79037995036`, часы работы 10:00–20:00 ежедневно, упоминание 4 филиалов.
- Логотип — текстовый wordmark «Shoes&Skin» с латунным «&» и SVG-строчкой под ним.
- Адаптив до 360px (проверены брейкпоинты 900/780/860/480/400px), видимый `:focus-visible`, `prefers-reduced-motion` (отключает анимации/переходы/smooth-scroll), `<title>`, meta description, Open Graph (`og:type/title/description/locale`), favicon — инлайн SVG data URI.
- Декоративные SVG либо помечены `aria-hidden="true"` напрямую, либо вложены в контейнер с `aria-hidden="true"` (звёзды рейтинга).
- Ручная проверка контраста (WCAG) по ключевым парам текст/фон: акцентный цвет для текста на светлом фоне намеренно затемнён до отдельного токена `--accent-on-light` (#7a5a2e, ≈5.5:1 на фоне bone), т.к. исходный `--accent-deep` (#96733f) давал только ≈3.8:1 и не проходил AA для обычного текста. Кольцо фокуса (`--focus-ring`) переключается между тёмным и светлым оттенком латуни в зависимости от тёмных/светлых секций, чтобы держать ≥3:1 в обоих случаях.
- Структурная проверка: все теги (`div/section/header/main/footer/nav/ul/li/form/article/figure`) сбалансированы, все `id` уникальны, скобки в CSS и JS сбалансированы.

## Допущения

- Точных адресов трёх дополнительных филиалов в исходных данных не было — указан только адрес БЦ Silver City. В блоке «Контакты» честно написано, что адрес ближайшего из остальных 3 филиалов уточняет администратор по телефону, а не выдуманы произвольные адреса.
- Реальных ссылок на 2ГИС/VK/Telegram-профили бизнеса предоставлено не было. В футере эти сети указаны как текстовые пункты без ссылок (не выдуманы URL). В блоке «Отзывы» кнопка ведёт на поисковый URL 2ГИС по названию (`https://2gis.ru/moscow/search/Shoes%20%26%20Skin`) — это best-effort ссылка на поиск, а не подтверждённая прямая ссылка на карточку организации.
- Тексты отзывов не публикуются на сайте намеренно (не было реальных цитат — правило задачи запрещало их выдумывать), вместо этого — честная агрегированная оценка и ссылка на первоисточник.
- Формулировки описания услуг («Глубокая деликатная чистка…», «Восстановление формы, подошвы…» и т.д.) — маркетинговые обобщения на основе индустриальной практики химчистки/реставрации обуви, не специфичные факты о процессах именно этой мастерской.

## Не могу проверить

- Lighthouse-аудит (производительность/SEO/доступность метрики) — Node.js и npm недоступны в этой системе, инструментов для запуска Lighthouse CLI нет. Контраст проверен вручную по формуле WCAG для ключевых пар текст/фон (см. раздел «Сделано»), но автоматического отчёта не было.
- Реальный визуальный рендеринг в браузере с применением `styles.css`/`script.js` — в среде предпросмотра `file://`-страницы вне рабочей папки агента открываются как статический DOM-снапшот, и подключение внешних `.css`/`.js` файлов блокируется (`ERR_BLOCKED_BY_CLIENT`), поэтому сборка проверена вручную: структура HTML (баланс тегов, уникальность id), баланс скобок в CSS/JS, расчёт контраста по формуле WCAG. Рекомендуется открыть `index.html` напрямую в обычном браузере для финальной визуальной проверки перед сдачей клиенту.
